# 数据源说明

本文档完整说明「国内期货量化模拟交易终端」用到的**全部外部数据源**：接口地址、请求方式、返回字段、解析规则、刷新频率、缓存策略与断网降级链路。

> **总原则**：所有数据均来自**公开接口与公开资料**，由你的电脑直接请求，**没有任何中间服务器**，数据不上传、不采集。

## 二、实时行情：东方财富

### 2.1 接口

| 项 | 值 |
|---|---|
| 地址 | `https://futsseapi.eastmoney.com/list/{marketId}` |
| 方法 | GET |
| Referer | `https://qhweb.eastmoney.com/` |
| 分页参数 | `orderBy=dm&sort=asc&pageIndex={页码}&pageSize=500&_={毫秒时间戳}` |
| 页面入口 | <https://qhweb.eastmoney.com/quote> |

### 2.2 市场 ID 对照（覆盖国内全部 6 家期货交易所）

| marketId | 交易所代码 | 全称 | 简称 |
|---|---|---|---|
| `113` | SHFE | 上海期货交易所 | 上期所 |
| `114` | DCE | 大连商品交易所 | 大商所 |
| `115` | CZCE | 郑州商品交易所 | 郑商所 |
| `225` | GFEX | 广州期货交易所 | 广期所 |
| `142` | INE | 上海国际能源交易中心 | 上期能源 |
| `220` / `8` | CFFEX | 中国金融期货交易所 | 中金所（两个 ID 合并去重） |

服务启动后用 7 线程并发拉取全部市场，按 `total` 自动翻页（单页 500 条，最多 8 页），得到**约 850 个真实月份合约**（主连/连续/指数/加权等衍生代码按名称过滤掉，不参与交易）。

### 2.3 返回字段（本终端实际消费的）

| 字段 | 含义 | 用途 |
|---|---|---|
| `dm` | 合约代码（如 `rb2610`） | 合约主键（大写化） |
| `name` | 合约名称（如 `螺纹钢2610`） | 名称 + 按「主连/连续/指数/加权」关键字过滤衍生代码 |
| `p` | 最新价 | 撮合价、盯市价（为 0 时回退 `zjsj`） |
| `zde` / `zdf` | 涨跌额 / 涨跌幅 | 列表展示（涨红跌绿） |
| `o` / `h` / `l` | 今开 / 最高 / 最低 | 列表展示 |
| `zjsj` | 昨结算价 | 保证金、涨跌停幅度基准 |
| `jjsj` | 今结算价 | 展示 |
| `zt` / `dt` | **涨停价 / 跌停价** | 涨跌停校验（委托越界直接拒绝；成交价夹在区间内） |
| `vol` / `cje` | 成交量 / 成交额 | 展示、主力合约推断 |
| `ccl` | 持仓量 | 展示、**主力合约推断（持仓量×1000 + 成交量选最大者）** |
| `rz` / `wp` / `np` | 日增仓 / 外盘 / 内盘 | 展示 |

### 2.4 刷新节奏

| 环节 | 频率 |
|---|---|
| 服务端后台拉取全市场 | 每 **30 秒**（线程池并发） |
| 前端面板拉取本地接口 | 每 **5 秒** |
| 手动刷新 | 面板「刷新行情」按钮（`/api/refresh`） |

拉取失败时**保留上一次数据**并在页头标注错误信息，不会清空面板。

## 三、K 线与分时：新浪财经

### 3.1 为什么 K 线走新浪而不是东方财富？

东方财富的 K 线域名（`push2his.eastmoney.com`）在部分网络环境下不可达（本机实测断连），而新浪期货接口**稳定且历史更长**：主力连续合约（如 `RB0`）日 K 可回溯到 **2009 年、4000+ 根**，足够长周期回测。实时报价仍保留东方财富，以复用其**涨停价 / 跌停价**字段。

### 3.2 接口清单

统一入口（JSONP 外壳 `var _x=(...);` 会被剥掉再按 JSON 解析；响应为 GBK 编码，解码失败回退 UTF-8）：

```
https://stock2.finance.sina.com.cn/futures/api/jsonp.php/var%20_x=/InnerFuturesNewService.{方法}?symbol={代码}
```

| 方法 | 用途 | 返回（本终端提取的字段） |
|---|---|---|
| `getDailyKLine` | 日 K | `[{d,o,h,l,c,v,p,s}]` 日期/开高低收/成交量/持仓量/结算 |
| `getFewMinLine&type={n}` | 分钟 K，`n` ∈ 1/3/5/15/30/60/120/240 | `[{d,o,h,l,c,v,p}]`（约最近 200 根） |
| `getMinLine` | 当日分时 | `[[时间,价,均价,量,持仓,昨收,日期], ...]` |

请求头带 `Referer: https://finance.sina.com.cn` 与浏览器 UA；超时 20 秒、失败重试 2 次（间隔递增 0.35s / 0.7s）。请求走**直连**（显式禁用系统代理），避免本机代理软件干扰。

### 3.3 合约代码规则

| 代码形式 | 含义 | 新浪符号 | 说明 |
|---|---|---|---|
| `RB2610` | 真实月份合约 | `rb2610`（小写） | 当日无数据时**自动回退主力连续**并在返回体标记 `fallback` |
| `RB0` | 主力连续（长历史） | `RB0` | 用于看盘与**回测**（2009 年至今） |
| — | 分时/分钟 K | 具体合约优先 | 主连的分钟数据新浪不一定有 |

映射逻辑见 `行情K线.py` 的 `sina_codes()`：一个面板代码会展开成**候选符号序列**，按顺序尝试直到取到数据。

### 3.4 周期体系与重采样

| 周期键 | 显示 | 数据来源 | 缓存 TTL |
|---|---|---|---|
| `m1` `m3` `m5` | 1/3/5 分 | 新浪 `getFewMinLine`（对应 type） | 60 秒 |
| `m15` `m30` | 15/30 分 | 同上 | 90 秒 |
| `m60` | 60 分 | 同上（type=60） | 120 秒 |
| `m120` `m240` | 2/4 小时 | 由 60 分 K 本地合成 | 180/300 秒 |
| `day` | 日 K | 新浪 `getDailyKLine` | 300 秒 |
| `week` | 周 K | 由日 K 按 **ISO 周**合成 | 600 秒 |
| `month` | 月 K | 由日 K 按**自然月**合成 | 900 秒 |

重采样规则：开=首根开、高=max、低=min、收=末根收、量=累加、持仓=末根。

### 3.5 双层缓存与断网降级

```
请求 → 内存缓存（TTL 内直接命中）
     → 磁盘缓存 行情缓存/k_{code}_{period}.json（联网失败时回退，返回体标记 stale=true）
     → 新浪接口（成功后同时写内存 + 磁盘）
```

- 磁盘缓存文件名做安全化处理（非字母数字转下划线），原子写入（先写 `.tmp` 再 `os.replace`）；
- 断网时面板页头会标注「**缓存**」与数据时间，交易功能不受影响（用最后一次快照价）。

## 四、合约参数：东方财富期货官网公示口径（已固化）

这部分**不是运行时接口**，而是从官网逐页抄录、固化在 `品种参数.json` 里的静态参数表（91 个品种），启动时加载、可编辑、重启生效。

| 参数 | 来源页面 | 说明 |
|---|---|---|
| **保证金率** | [做一手需要多少钱](https://qhweb.eastmoney.com/bzj/low) · [交易提示](https://www.eastmoneyfutures.com/pages/service/jyts.html) | 东方财富期货**公司保证金比例**（如螺纹钢 18%、沪金 35%、集运欧线 40%） |
| **手续费** | [公司手续费标准](https://www.eastmoneyfutures.com/pages/service/sxf.html) | 开仓 / 平昨 / 平今三档；「按手数」（元/手）或「按成交额」（比例）两种模式；官网口径为「不高于以下标准」 |
| **交易规则** | [品种及交易规则](https://www.eastmoneyfutures.com/pages/service/jygz.html) | 交易单位（合约乘数）、最小变动价位、合约月份、最后交易日 |
| **涨跌停板** | [交易提示](https://www.eastmoneyfutures.com/pages/service/jyts.html) | 每日涨跌幅度（相对昨结算的 ± 比例，如螺纹钢 ±7%、碳酸锂 ±15%） |
| **交易时间** | [交易时间](https://qhweb.eastmoney.com/tradinghours) | 日盘/夜盘时段、集合竞价、夜盘收市三档（23:00 / 次日 01:00 / 次日 02:30） |

**两个口径提醒**（`品种参数.json` 的 `_数据来源._口径提醒` 同款）：

1. 官网手续费是期货公司**默认标准**（多数品种约为交易所标准的 3 倍）。想模拟交易所底线费率，把面板「手续费折扣」设为 0.33 左右即可；
2. **临近交割月保证金会临时上调**（官网「特殊合约参数调整」列，如 2610 合约 60%），本表按一般月份主力合约标准记录，未逐合约区分。

**准确性对账**：`自测_参数对账东方财富.py` 用官网「做一手保证金金额」逐品种反算（价格 × 合约乘数 × 保证金率），**87 个品种偏差全部为 0.00%**。据此还修正了一处易错点：鸡蛋报价单位是「元/500 千克」，合约乘数为 **10** 而非交易单位的 5 吨。

## 五、离线快照（快照/）

联网失败时，实时行情自动回退到本地快照，面板页头标注「使用快照」与快照时间。快照由配套的「[国内期货数据终端](https://github.com/chenzhuanxin/china-futures-data-terminal)」采集产出，随项目分发：

| 文件 | 内容 | 用途 |
|---|---|---|
| `contracts.json` | 1075 个合约（849 真实 + 226 衍生）的名称、代码、交易所、行情 | **断网兜底行情** |
| `varieties.json` | 87 个品种的板块归属与聚合数据 | 板块筛选、品种汇总 |
| `weighted.json` | 82 个加权指数的 K 线 | 加权指数查看 |
| `lhb_index.json` | 74 条龙虎榜索引 | 关联数据终端 |
| `newslinks.json` | 新闻链接 | 侧栏资讯 |
| `categories.json` | 交易所/板块分类树 | 列表筛选 |
| `meta.json` | 快照元信息（生成时间、交易日、来源、统计） | 页头展示快照新鲜度 |

本快照样本：生成于 `2026-10-04 13:35:50`，交易日 `2026-09-30`，覆盖 6 家交易所、87 个品种、54 个夜盘品种。可自行用数据终端重新生成并替换。

## 六、合规与稳定性说明

1. **公开数据、低频访问**：实时行情 30 秒一次（全市场一次批量拉取），K 线按需单合约拉取且有 TTL 缓存——远低于任何商用爬虫强度，属于正常浏览量级；
2. **直接请求、无转售**：数据只在你本机展示，不存储到任何云端、不提供对外服务；
3. **接口为公开网页端点**，非官方开放 API，**不保证永续可用**；若新浪/东财调整接口，可修改 `行情K线.py` / `模拟交易服务.py` 顶部的 URL 常量适配，或直接使用离线快照；
4. 行情可能**延迟、缺失或有误**，模拟盘成交以本地撮合为准，**不构成任何投资建议**；
5. 本机若开了代理软件，可能导致接口误报失败——终端已对行情请求显式直连，但仍建议将 `127.0.0.1` 加入代理直连规则。
