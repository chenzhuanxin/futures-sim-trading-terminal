# 配置说明

本文档覆盖「国内期货量化模拟交易终端」的**全部可配置项**：配置文件、界面设置、资金管理参数、账户数据结构、命令行参数与打包配置。

**配置生效方式一览**：

| 配置 | 存放位置 | 修改方式 | 生效时机 |
|---|---|---|---|
| 品种参数（乘数/保证金/手续费/涨跌停/时段） | `品种参数.json` | 文本编辑 | **重启服务** |
| 交易设置（保证金倍数/滑点/强平线…） | `账户数据/acc_<uid>.json` 的 `settings` | 面板右上角「设置」 | **立即** |
| 资金管理参数 | 各策略自带（`strategies.json`）/ 回测 / 复盘表单 | 面板表单或一键预设 | 保存/运行时 |
| 账户与银行卡 | `账户数据/users.json` | 面板「账户 · 银期转账」页 | 立即 |
| 服务端口 / 启动行为 | 命令行参数 | 启动命令 | 启动时 |
| 打包内容 / 图标 / 版本号 | `打包成exe.py` 顶部常量 | 文本编辑 | 重新打包时 |

## 一、品种参数.json（合约参数表）

**这是最重要的配置文件**：91 个品种的合约乘数、保证金率、手续费、涨跌停板、交易时段全部在这里，模拟撮合、回测、复盘、对账共用同一张表。

### 1.1 顶层结构

```jsonc
{
  "_说明": "……字段含义总述",
  "_数据来源": { "保证金率": "官网 URL", "手续费": "……", "_抓取日期": "2026-10-05" },
  "默认保证金倍数": 1.0,     // 新账户的初始「保证金倍数」设置
  "默认手续费折扣": 1.0,     // 新账户的初始「手续费折扣」设置
  "交易时段": { "日盘_商品": "09:00-10:15，10:30-11:30，13:30-15:00", "夜盘_2300": "21:00-23:00", "…": "…" },
  "品种": { "CU": { … }, "RB": { … }, … }   // 91 个品种
}
```

### 1.2 单个品种的字段（以沪铜为例）

```jsonc
"CU": {
  "名称": "沪铜",
  "交易所": "上期所",
  "合约乘数": 5,            // 1 手对应的报价单位数量（铜=5吨/手）
  "最小变动价位": 10,        // 1 跳 = 10 元/吨 → 每跳价值 = 10 × 5 = 50 元/手
  "单位": "吨/手",
  "保证金率": 0.23,          // 东方财富期货「公司保证金比例」
  "涨跌停板": 0.09,          // 相对昨结算 ±9%
  "合约月份": "1~12月",
  "最后交易日": "合约月份15日（顺延）",
  "夜盘": "0100",            // 2300 / 0100 / 0230 三档，空串=无夜盘
  "手续费": {
    "模式": "按成交额",       // 或「按手数」
    "开仓": 0.00015,          // 按成交额 = 价格×乘数×手数×比例；按手数 = 元/手
    "平仓": 0.00015,          // 平仓 = 平昨仓
    "平今": 0.0003            // 当日平仓单独计提（铜平今加收）
  }
}
```

**关键公式**：

```
合约价值   = 最新价 × 合约乘数 × 手数
每跳价值   = 最小变动价位 × 合约乘数            （如铜 50 元/跳，螺纹 1 元/跳）
一手保证金 = 最新价 × 合约乘数 × 保证金率 × 「设置里的保证金倍数」
一手手续费 = 按手数：   费率 × 手数 × 「手续费折扣」
             按成交额：价格 × 乘数 × 手数 × 费率 × 「手续费折扣」
盈亏       = (平仓价 − 开仓价) × 合约乘数 × 手数 × 多空方向
```

### 1.3 修改示例

- 你的期货公司螺纹钢保证金收 13%：把 `RB.保证金率` 从 `0.18` 改成 `0.13`；
- 想免手续费测试：不改文件，把面板「手续费折扣」设为 0 即可；
- 改完**重启服务**生效；面板「交易规则与费率」页会立即反映新值（重启后）。

> 注意「合约乘数」与「交易单位」不是一回事：乘数 = 1 手对应的**报价单位**数量。鸡蛋报价按「元/500 千克」，所以乘数是 10 而非交易单位的 5 吨——这类坑已通过对账修正。

## 二、交易设置（界面 · 右上角「设置」）

按账户独立存储（`账户数据/acc_<uid>.json` 的 `settings`），改完立即生效：

| 设置项 | 默认 | 取值 | 说明 |
|---|---|---|---|
| 保证金倍数 | `1.0` | > 0 | 在东方财富公司保证金率基础上整体放大（如 1.2 = 加收 20%） |
| 手续费折扣 | `1.0` | ≥ 0 | 相对官网公司手续费标准；`0.33` ≈ 交易所底线费率；`0` = 免手续费 |
| 市价单滑点 | `0` 跳 | ≥ 0 | 1 跳 = 最小变动价位；滑点方向始终**对成交方不利** |
| 自动强平 | 开 | 开/关 | 关闭后风险度超标只警示不强平 |
| 强平线 | `1.0`（100%） | > 0 | 风险度 = 占用保证金 ÷ 动态权益，达到即逐笔强平（按亏损从大到小） |
| 仅交易时段下单 | 关 | 开/关 | 开启后非交易时段拒绝开仓（便于只用最新快照价验证策略） |
| 涨跌停校验 | 开 | 开/关 | 拒绝越界委托价；成交价一律夹在当日涨跌停区间内 |

面板同时提供「重置账户（保留资金）」与「清空重置」两个快捷操作，等价于删除/清空 `acc_<uid>.json`。

## 三、资金管理参数（策略 / 回测 / 复盘共用）

资金管理区块在**策略编辑、回测表单、复盘表单**三处出现，参数完全一致，共 4 组 31 项。全部参数的默认值定义在 `资金管理.py` 的 `DEFAULTS`：

### 3.1 ① 手数模式（做多少手）

| 参数 | 默认 | 说明 |
|---|---|---|
| 手数模式 | **风险固定** | `fixed` 固定手数 / `ratio` 保证金比例 / `risk` 风险固定 / `atr` 波动率目标 / `kelly` 分数凯利 |
| 固定手数 | `1` | 仅 `fixed` 模式 |
| 资金比例% | `30.0` | 仅 `ratio`：保证金 = 权益 × X% 倒算手数 |
| 单笔风险% | `1.0` | 仅 `risk`：单笔最大亏损 = 权益 × X%，再按止损距离倒算手数（**推荐**） |
| 目标波动% | `2.0` | 仅 `atr`：每根 K 线波动 ≈ 权益 × X% |
| 凯利分数 | `0.5` | 仅 `kelly`：0.5 = 半凯利（保守化） |
| 凯利上限% | `30.0` | 凯利仓位封顶（另有下限 5%、最少样本 10 笔，样本不足自动退回风险固定） |
| 单笔最大手数 | `20` | 所有模式共用的硬上限 |
| 最小手数 | `1` | 计算结果不足 1 手时的下限 |

### 3.2 ② 止损方式（错了在哪退出）

| 参数 | 默认 | 说明 |
|---|---|---|
| 止损方式 | `ATR` | `atr` / `pct` / `ticks` / `none` |
| ATR周期 | `14` | ATR 计算周期 |
| ATR倍数 | `2.0` | 止损距离 = ATR × 倍数 |
| 止损% | `2.0` | 仅 `pct`：距离 = 开仓价 × X% |
| 止损跳数 | `20` | 仅 `ticks`：距离 = N 跳 × 最小变动价位 |

> 「不设止损」与「风险固定」同开时，止损距离为 0 无法倒算手数，会**自动退回固定手数**并在摘要中提示。

### 3.3 ③ 风险闸门（什么时候不许做）

| 参数 | 默认 | 说明 |
|---|---|---|
| 保证金占用上限% | `50.0` | 该笔下单后总占用超限则拒单 |
| 最大回撤熔断% | `20.0`（0=关） | 权益自峰值回撤超限 → 停止开新仓，创新高自动解除 |
| 熔断后清仓 | 开 | 熔断同时强制平掉全部持仓 |
| 连亏减仓笔数 | `3`（0=关） | 连亏 N 笔后手数打折 |
| 连亏折扣 | `0.5` | 0.5 = 手数减半 |
| 连亏停手笔数 | `0`（关） | 连亏 N 笔后停止开新仓 |
| 日内亏损上限% | `0.0`（关） | 当日亏损达权益 X% 后当日不再开仓 |

### 3.4 ④ 持仓管理（加仓与移动止损）

| 参数 | 默认 | 说明 |
|---|---|---|
| 加仓模式 | 不加仓 | `off` / `pyramid` 金字塔加仓 |
| 最大加仓次数 | `2` | 最多追加几次 |
| 加仓触发% | `1.0` | 浮盈 ≥ 触发% × (已加次数+1) 才追加 |
| 加仓手数比例 | `0.5` | 每次加仓手数 = 首仓 × 比例^k（递减，海龟式） |
| 最大总手数 | `0`（不限） | 加仓后总手数封顶 |
| 移动止损 | 关闭 | `off` / `be` 保本 / `atr` 跟随ATR |
| 保本触发% | `1.5` | 浮盈达标后触发（be：止损移到开仓价；atr：跟随最高价回撤） |
| 跟随ATR倍数 | `2.0` | 跟随止损的回撤幅度 |

### 3.5 四套科学预设（一键套用）

| 预设 | 核心参数 | 适合 |
|---|---|---|
| **稳健趋势（推荐）** | 风险固定 1% + ATR(14)×2 止损 + 保本移动止损(2%) + 熔断 20% + 连亏 3 笔减半 | 大多数人的起点 |
| **海龟式趋势（加仓）** | 风险固定 1.5% + ATR(20)×2 + 金字塔加仓(2次,触发1.5%,比例0.5) + 跟随ATR + 熔断 25% | 趋势行情放大利润 |
| **保守低频（低回撤）** | 风险固定 0.5% + 百分比止损 2% + 熔断 15% + 连亏 2 笔减半 + 连亏 5 笔停手 + 日内亏损上限 3% | 回撤优先 |
| **波动率均衡（自适应）** | 波动率目标 2% + ATR(14)×2.5 止损 + 熔断 18%（不清仓） | 仓位随品种波动自动伸缩 |

> 预设同时携带推荐的策略参数（如稳健趋势配套均线周期 20）。回测与实盘挂载**共用同一套资金管理代码**（`MoneyManager.plan()`），回测里的手数行为就是实盘行为。

## 四、账户数据文件（账户数据/，仅存本机）

| 文件 | 内容 | 可否删除 |
|---|---|---|
| `users.json` | 账户注册表：全部模拟账户（登录账号、加盐 sha256 密码、交易账户号）、银行卡（卡号掩码、卡密码哈希、卡余额、转账流水）、当前登录账户 | 删除后下次启动自动重建默认账户 sim001 |
| `acc_<uid>.json` | 每个账户的资金状态：结存、持仓（今昨仓）、委托、成交、资金流水、权益曲线点、`settings` | 删除 = 清空该账户资金 |
| `strategies.json` | 策略库（含每条策略的资金管理参数） | 删除后自动恢复内置示例策略 |
| `backtests/` | 回测历史记录 | 可删 |

**安全说明**：所有密码（登录/资金/银行卡）一律 `sha256(盐 + 密码)` 落盘，任何接口不回传明文；忘记密码无法找回（模拟盘，直接删掉 `users.json` 重来即可）。

**备份 / 迁移**：整个 `账户数据/` 目录拷走即完成备份；想清空重练，删除该目录后重启。

## 五、命令行参数

```
python 模拟交易服务.py [--port 8908] [--no-browser] [--offline]
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--port` | `8908` | 监听端口；被占用时自动向后寻找空闲端口（8909、8910…） |
| `--no-browser` | 关 | 不自动打开浏览器（自动化测试 / 服务器场景） |
| `--offline` | 关 | 跳过联网，直接用 `快照/` 离线行情启动 |

exe 同样支持这些参数（如 `期货模拟交易终端.exe --port 9000 --no-browser`）。重复双击 exe 不会重复开服务，会自动复用已运行实例并直接开面板。

## 六、源码 / exe 双模式与资源覆盖

`路径工具.py` 把路径分为两类（详见其文件头注释）：

| 类别 | 内容 | 源码运行 | 打包 exe |
|---|---|---|---|
| **只读资源** | `交易面板.html`、`vendor/`、`品种参数.json`、`快照/` | 脚本目录 | 内嵌进 exe（`sys._MEIPASS` 解压临时目录） |
| **可写数据** | `账户数据/`、`行情缓存/` | 脚本目录 | **exe 所在目录**（绿色便携，数据跟 exe 走） |

**不重新打包就改配置**：在 exe 旁边放一份同名文件即可**覆盖内嵌资源**——

```
期货模拟交易终端.exe
品种参数.json               ← 放这里，优先于内嵌版（改保证金/手续费）
vendor/quant-terminal.css   ← 改皮肤
```

删除 exe 旁的同名文件即恢复内嵌版。

## 七、打包配置（打包成exe.py）

一键打包脚本顶部常量，按需修改后运行 `python 打包成exe.py`（需 PyInstaller + Pillow）：

| 常量 | 默认 | 说明 |
|---|---|---|
| `VERSION` | `"1.0.0.0"` | 写入 exe 属性的版本号 |
| `ENTRY` | `模拟交易服务.py` | 打包入口 |
| `DATA_MAP` | html / 品种参数 / vendor / 快照 | 内嵌进 exe 的只读资源清单 |
| `HIDDEN` | 6 个中文模块名 | 中文文件名模块需显式声明，防止 PyInstaller 漏收 |
| `EXCLUDES` | tkinter、unittest 等 | 明确用不到的大块头，给 exe 瘦身（**不能排 email/html**，http.server 依赖） |

脚本流程：现画图标（深蓝底 + 红绿 K 线柱 + 上升折线）→ 生成版本信息与 spec → PyInstaller 构建 → 移动产物到项目根 → 自动跑一次 `--help` 自检。**构建前请关闭正在运行的旧 exe**。
