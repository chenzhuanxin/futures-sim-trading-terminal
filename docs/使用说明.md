# 使用说明

> 本文档是六大页签的**逐页操作指南**。配套阅读：
> [项目说明（README）](../README.md) · [数据源说明](数据源说明.md) · [配置说明](配置说明.md)
>
> 配套「[国内期货数据终端](https://github.com/chenzhuanxin/china-futures-data-terminal)」的**量化模拟交易面板**，五大模块：
> **① 行情**（实时报价 + 分时 + 1/3/5/15/30/60 分 · 2/4 小时 · 日/周/月 K 线，主图副图技术指标可自由加载）
> **② 模拟交易**（资金注入 / 提取、多空双向、开平仓、限价撮合、保证金与风险度、自动强平、权益曲线）
> **③ 策略选股**（策略扫描全市场品种池，列出最新信号）
> **④ 策略交易**（可添加自定义策略，挂载后按 K 线自动开平仓，默认示例＝穿越 5 日日 K 均线）
> **⑤ 回测 · 复盘**（无未来函数的策略回测 + 逐根回放的手动复盘）
>
> **交易规则、手续费、保证金全部对齐东方财富期货官网公示口径。**
> **纯 Python 标准库 + 单页 HTML，零第三方依赖，数据只存本机。**

**设计：陈专新　微信：gongqizi0**

## 一、快速开始

三种启动方式任选其一：

- **双击 `期货模拟交易终端.exe`**（绿色单文件版，无需装 Python，见第十四章）；
- 双击 **`启动模拟交易.bat`**（自动找本机 Python 3.9+）；
- 命令行 `python 模拟交易服务.py`。

共同行为：

- 自动检测本机 Python（3.9+，无需 pip install 任何东西）；
- 服务默认跑在 `http://127.0.0.1:8908/`，浏览器自动打开面板；
- 关闭命令行窗口即停止服务；重复双击不会重复开服务；
- 端口被占用时自动向后寻找空闲端口（8909、8910…）。

首次使用：默认账户 **sim001**（登录密码 `123456`）已自动登录；先到「**账户 · 银期转账**」页用银期转入注入资金（或点右上角「资金注入」走快捷通道，建议 10 万），然后在左侧点任意合约即可下单。
面板顶部有 6 个页签：**行情 · 技术指标 / 模拟交易 / 策略选股 · 策略交易 / 策略回测 / 复盘 / 账户 · 银期转账**，点一下即可切换。

## 二、功能总览

| 模块 | 说明 |
|---|---|
| **实时行情** | 全市场约 850 个合约的最新价、涨跌幅、持仓量；每 5 秒刷新，涨红跌绿 |
| **分时图** | 当日走势与均价线，来自新浪期货分时接口，逐笔点还原 |
| **K 线（9 个周期）** | 1 / 3 / 5 / 15 / 30 / 60 分、2 / 4 小时、日 / 周 / 月；周月 K 由日 K 合成 |
| **技术指标（主图）** | MA、EMA、BOLL、SAR，参数可改，多组叠加 |
| **技术指标（副图）** | VOL、MACD、KDJ、RSI、WR、BIAS、OBV、DMI、CCI、ATR，可同时加载多组 |
| **策略选股** | 选定一个策略，扫描全部品种（或指定板块 / 合约），列出命中信号与所属可交易合约 |
| **策略交易** | 策略可新增 / 编辑 / 复制 / 删除 / 挂载；挂载后后台每 30 秒按最新 K 线自动开平仓（可先「仅信号」观察） |
| **资金管理与仓位管理** | 策略 / 回测 / 复盘三处共用：5 种手数模式（固定 / 保证金比例 / **风险固定** / 波动率目标 / 分数凯利）、4 种止损方式、风险闸门（回撤熔断 / 连亏减仓停手 / 日内亏损上限 / 保证金占用上限）、金字塔加仓与移动止损；4 套科学预设一键套用 |
| **策略回测** | 无未来函数回测：收益 / 年化 / 最大回撤 / 胜率 / 盈亏比 / 夏普 / 连续亏损 + 资金管理 KPI（期望R / 累计R / 保证金占用 / 熔断 / 拒单）；K 线买卖点 + 净值曲线；支持区间、止盈、滑点与整套资金管理 |
| **复盘** | 手动练习与自动跟随两种模式；K 线成交点 + **资金变化曲线**（动态权益 / 结存 / 浮动盈亏 / 回撤）；**复盘记录可折叠展开（每笔 24 字段）、可切换明细表、可复制（CSV/TSV/摘要）、可导出（CSV/TSV/JSON/JSONL），结束后依然可用** |
| **账户与银期转账** | 多模拟账户（登录账号/登录密码/交易账户/资金密码，状态互相隔离，可添加/删除）；模拟银行卡可添加/解绑；银期转入验银行密码、转出验银行密码+资金密码且不超可用资金，双边留痕，密码加盐哈希 |
| **资金注入 / 提取** | 跳过银期的快捷入金与出金（管理员口径）；出金上限 = 可用资金（占用中的保证金需先平仓释放） |
| **模拟下单** | 买入开多 / 卖出开空 / 平多 / 平空；市价（最新价成交）与限价（挂单撮合）两种方式 |
| **今仓 / 昨仓** | 自动区分今昨仓，平仓支持「自动（先平昨再平今）/ 只平今 / 只平昨」三种方式 |
| **保证金与风险度** | 按东方财富「公司保证金比例」实时计算占用保证金、可用资金、风险度、最多可开手数 |
| **涨跌停板** | 按东方财富「每日涨跌幅度」拒绝越界委托价，成交价也被夹在当日涨跌停区间内（可在设置中关闭） |
| **交易规则** | 面板内直接展示每个品种的交易单位、最小变动价位、每跳价值、合约月份、最后交易日、日盘 / 夜盘时段 |
| **手续费** | 按东方财富「公司手续费标准」计提（元/手 或 成交额比例），开仓 / 平昨 / 平今三档费率，平今单独计提 |
| **浮动盈亏** | 持仓逐笔盯市（多空双向），平仓时一次性转为已实现盈亏并计入结存 |
| **自动强平** | 风险度（占用保证金/动态权益）触及强平线时，按亏损从大到小逐笔强平，全程写日志 |
| **权益曲线** | 每 15 秒及每次成交后记一点：动态权益 / 静态结存 / 占用保证金三条曲线（ECharts） |
| **合约行情** | 6 大交易所全部真实月份合约（约 850 个），支持搜索、交易所与品种类型筛选、排序 |
| **规则费率表** | 「交易规则与费率」标签页：91 个品种全参数一览，可搜索，含「做一手约需」实时估算 |
| **交易日志** | 出入金、成交、撤单、风控强平、设置变更全程留痕 |

## 四、数据来源（全部为东方财富期货官网公示口径）

| 数据 | 来源 | 说明 |
|---|---|---|
| 实时行情 | `futsseapi.eastmoney.com`（东方财富期货行情） | 服务每 30 秒后台刷新一次，面板每 5 秒拉取一次；含最新价、结算价、**涨停价 / 跌停价** |
| **K 线（日/周/月）** | `stock2.finance.sina.com.cn`（新浪财经期货 `getDailyKLine`） | 主力连续合约（如螺纹钢 `RB0`）可取到 **2009 年至今 4000+ 根**，足够长周期回测 |
| **K 线（分钟）** | 新浪财经 `getFewMinLine` | 1/3/5/15/30/60 分、2/4 小时，分钟级按「最近 200 根」拉取 |
| **分时** | 新浪财经 `getMinLine` | 当日逐笔走势 + 均价线 |
| 周期合成 | 本地重采样 | 周 K 按 ISO 周、月 K 按自然月，由日 K 合并（开=首、高=最大、低=最小、收=末、量=累加） |
| **保证金率** | [做一手需要多少钱](https://qhweb.eastmoney.com/bzj/low) · [交易提示](https://www.eastmoneyfutures.com/pages/service/jyts.html) | 东方财富期货**公司保证金比例**（如螺纹钢 18%、沪金 35%、集运欧线 40%） |
| **手续费** | [公司手续费标准](https://www.eastmoneyfutures.com/pages/service/sxf.html) | 官网更新 2026-09-21；开仓 / 平昨 / 平今三档，官网口径为「不高于以下标准」 |
| **交易规则** | [品种及交易规则](https://www.eastmoneyfutures.com/pages/service/jygz.html) | 交易单位（合约乘数）、最小变动价位、合约月份、最后交易日 |
| **涨跌停板** | [交易提示](https://www.eastmoneyfutures.com/pages/service/jyts.html) | 每日涨跌幅度（如螺纹钢 ±7%、碳酸锂 ±15%、国债 ±0.5%） |
| **交易时间** | [交易时间](https://qhweb.eastmoney.com/tradinghours) | 日盘 / 夜盘时段与开市前集合竞价（夜盘品种 20:55 起，无夜盘商品 08:55 起，股指国债 09:25 起） |
| 离线兜底 | `快照/contracts.json` | 联网失败时自动启用，页头会标注「使用快照」与快照时间 |

> **两种费率口径的区别**：官网手续费是期货公司「默认标准」（多数品种约为交易所标准的 3 倍，如螺纹钢万 3、黄金 60 元/手、欧线集运平今万 36）。想模拟交易所底线费率，把「手续费折扣」设为 0.33 左右即可。
> 修改 `品种参数.json` 后重启服务即可生效（比如把某个品种的保证金率改成你期货公司实际收取的值）。

**参数准确性已做全网对账**：用官网「做一手保证金金额」逐品种反算（价 × 乘数 × 保证金率），**87 个品种偏差全部为 0.00%**，并据此修正了鸡蛋的合约乘数（报价按 500 千克，乘数为 10 而非交易单位的 5 吨）。

## 五、交易规则如何落地（东方财富口径）

| 规则 | 模拟盘的实现 |
|---|---|
| **合约乘数 / 最小变动价位** | 取自官网「品种及交易规则」，保证金、盈亏、手续费、每跳价值全部按它计算 |
| **保证金** | 一手保证金 = 最新价 × 合约乘数 × 公司保证金比例；逐笔盯市 |
| **手续费** | 开仓 / 平昨 / 平今三档；按手数的品种收固定元/手，按成交额的品种收 价×乘数×手数×比例 |
| **涨跌停板** | 行情接口返回当日涨停价 / 跌停价；越界委托直接拒绝并留在「委托」列表（状态=已拒绝），成交价一律夹在区间内 |
| **交易时段** | 按官网「交易时间」判断：商品日盘 09:00-10:15 / 10:30-11:30 / 13:30-15:00；股指 09:30-11:30 / 13:00-15:00；国债至 15:15；夜盘分 23:00 / 次日 01:00 / 次日 02:30 三档收市；开市前 5 分钟集合竞价计入 |
| **平今加收** | 铜、焦炭、生猪、苹果、股指、欧线集运、多晶硅等品种平今费率单独计提 |
| **今昨仓** | 今仓跨自然日自动转昨仓，平仓默认「先平昨再平今」 |

**参数可改**：指标以 `名字(参数1,参数2,...)` 的文本形式表达，例如把 `MA(5,10,20,60)` 改成 `MA(3,8,13,34)` 即可。点「指标库」按钮可以查看全部指标与默认参数。

**从图下单**：点「去交易」会带着当前合约跳到模拟交易页，直接下单。

> 数据源分工：**实时报价走东方财富，K 线与分时走新浪财经**。原因是东方财富的 K 线域名（`push2his.eastmoney.com`）在部分网络环境下不可达，而新浪期货接口稳定且历史更长（主力连续可到 2009 年），更适合回测。断网时自动回退到本地 `行情缓存/`，页头会标注「缓存」。

## 七、策略选股与策略交易

「策略选股 · 策略交易」页签分两块：上半是**策略库**，下半是**选股扫描**与**挂载运行**。

### 7.1 内置策略模板（8 个）

| 模板 | 参数 | 信号逻辑 |
|---|---|---|
| **穿越 N 周期均线** | 周期（默认 **5**）、方向 | 收盘价上穿均线开多、下穿均线开空（**这就是示例「穿越 5 日日 K 均线」**） |
| 双均线交叉 | 快周期、慢周期 | 快线上穿慢线开多、下穿开空 |
| MACD 金叉死叉 | 快、慢、信号 | DIF 上穿 DEA 开多，下穿开空 |
| KDJ 金叉死叉 | N、K、D | K 上穿 D 开多，下穿开空 |
| 布林带突破 | 周期、倍数 | 收盘上穿上轨开多、下穿下轨开空 |
| 唐奇安通道 | 周期 | 突破 N 日新高开多、新低开空 |
| RSI 超买超卖 | 周期、下轨、上轨 | RSI 上穿下轨开多、下穿上轨开空 |
| 自定义条件 | 左值、算子、右值 | 例：左值 `MA(5)`、算子 `上穿`、右值 `MA(20)`，也支持 `价格` 作为左值 |

每个策略还有三个通用参数：**方向**（双向 / 仅做多 / 仅做空）、**每次手数**、**止损% / 止盈%**（填 0 表示不启用）。手数与止损已统一交给「资金管理与仓位管理」区块（见 7.5）。

### 7.2 新增 / 编辑策略

点「新建策略」→ 选模板 → 填参数 → 点「保存」即可。策略库里每条都能 **编辑 / 复制 / 删除 / 启用停用**。所有策略持久化在 `账户数据/strategies.json`，重启不丢。

### 7.3 策略选股（扫描）

在「策略选股」区选一个策略、设好**回看根数**与**扫描范围**（全部品种 / 指定板块 / 指定合约），点「开始扫描」。程序会在每个品种的 K 线上跑一遍该策略，列出**最新一根是否出信号**、信号方向、现价与对应的**可交易具体合约**。

> 「主力连续」代码（如 `RB0`）只用于看盘与回测；**下单时程序会自动换成当前主力月份的具体合约**（按持仓量×1000 + 成交量选最大者，如 `rb2610`）。

### 7.4 策略交易（挂载自动运行）

在策略库里点「挂载」即进入自动运行：

- 后台每 **30 秒**扫一次该策略的品种池，按最新 K 线出信号就自动下单；
- 勾选「仅记录信号（不下单）」时只记信号不动仓，适合先观察策略在真实行情下的表现；
- 「运行状态」区会显示每个挂载策略的最近信号、最近动作、成交回报；
- 点「停用」即可卸下。所有动作都写进交易日志。

### 7.5 资金管理与仓位管理（策略 / 回测 / 复盘 三处共用）

策略只负责「什么时候进出」，**做多少手、错了在哪退出、什么时候不许做**由这一块决定。表单分四组，可单独调整，也可一键套用科学预设：

**① 手数模式（做多少手）**

| 模式 | 说明 |
|---|---|
| 固定手数 | 每次固定 N 手，最简单 |
| 保证金比例 | 保证金占权益的固定百分比 |
| **风险固定（推荐）** | 手数 = 权益 × 单笔风险% ÷ 止损距离金额，让**每笔亏损金额可控** |
| 波动率目标 | 按 ATR 反推手数，使仓位波动 ≈ 目标波动% |
| 分数凯利 | 按历史胜率/盈亏比的分数凯利公式（样本不足自动退回风险固定） |

**② 止损方式（错了在哪退出）**：ATR（波动止损）/ 百分比 / 固定跳数 / 不设止损；「不设止损」与「风险固定」同开时自动退回固定手数并提示。

**③ 风险闸门（什么时候不许做）**：最大回撤熔断（可清仓）、连亏 N 笔手数打折、连亏 N 笔停手、日内亏损上限、保证金占用上限、单笔最大/最小手数。

**④ 持仓管理（让利润奔跑）**：金字塔加仓（浮盈达标按比例递增加仓）、移动止损（保本 / 跟随 ATR）。

**四套科学预设**（点按钮一键套用）：

| 预设 | 适合 |
|---|---|
| **稳健趋势（推荐）** | 风险固定 1% + ATR 止损 + 保本移动止损，大多数人的起点 |
| 海龟式趋势（加仓） | 风险固定 1.5% + 金字塔加仓 + 跟随 ATR，趋势行情放大利润 |
| 保守低频（低回撤） | 风险固定 0.5% + 百分比止损 + 日内亏损上限 3%，回撤优先 |
| 波动率均衡（自适应） | 波动率目标 2%，仓位随品种波动自动伸缩 |

回测与实盘挂载**共用同一套资金管理代码**，回测里看到的手数行为就是实盘行为。

## 八、策略回测

「策略回测」页签：左侧填参数，右侧出结果。

**可调参数**：策略与参数、品种（支持主力连续如 `RB0`，历史最长）、周期、回测区间（起止日期）、初始资金、止盈% / 滑点（跳）/ 手续费折扣 / 保证金倍数，以及与策略页同一套**资金管理与仓位管理**区块（含预设一键套用）。

**成交口径（无未来函数）**：第 i 根 K 线**收盘**出信号 → 第 i+1 根 K 线**开盘**成交；**手数按「上一根收盘权益」由资金管理算出**；加仓按触发当根收盘价成交。止损 / 止盈在同一根 K 线内用开盘价与最高/最低价判定。手续费与保证金直接复用 `品种参数.json`（含开仓 / 平昨 / 平今三档、按手数与按成交额两种模式），与模拟交易完全一致。

**输出**：

- **绩效卡片**：总收益率、年化收益率、最大回撤（含起止日期）、交易次数、胜率、盈亏比、总盈亏、总手续费、夏普比率、最大连续亏损、平均持仓根数、多头/空头分别胜率；
- **资金管理与仓位卡片**：手数模式、止损方式、期望 R / 累计 R（R = 净盈亏 ÷ 单笔风险额）、平均与峰值保证金占用、熔断触发次数、风控拒单、资金不足跳过，以及资金管理方案一句话摘要；
- **K 线买卖点图**：只标「开仓」点，避免平仓点糊满图；
- **净值曲线**：动态权益随时间的走势；
- **交易明细表**：逐笔列出开平时间、方向、价格、手数、**止损价 / 风险额 / R**、离场类型（信号 / 止损 / 移动止损 / 熔断）、开平仓理由。

**参数扫描**：点「批量：均线周期 5/10/20/30/60」会一次性跑完 5 组参数，按总收益排序输出，用于快速找参数。历史回测记录可在「回测记录」里回看。

## 九、复盘

「复盘」页签支持**手动练习**与**自动跟随**两种玩法：

1. 选品种、周期、区间根数、**初始资金**、止盈%，选是否**叠加策略信号**，选**交易方式**（手动复盘 / 自动跟随策略信号），下方同样有**资金管理区块**（自动模式下由策略出信号、资金管理算手数）；
2. 点「开始复盘」，程序取一段 K 线并把光标停在起点；控制栏：`回到起点 / 上一根 / 下一根 / 前进 5 根 / 自动播放（可调速度）/ 跳到末尾`，也可拖进度条；
3. **手动模式**：用「开多 / 开空 / 平仓」在当前位置手动下单；**自动跟随**：点「🤖 自动跟随信号」，策略出信号、资金管理算手数，自动开平；
4. **两张图**：上面是 K 线 + 成交点（▲B/▼S 策略信号、◆ 我的操作），下面是**资金变化曲线**（动态权益 / 结存 / 浮动盈亏柱 / 回撤，右侧轴 %，成交点标在曲线上）；
5. **复盘记录**（核心交付）：
   - 默认**折叠视图**：一笔交易一行（方向、开平时间价格、持仓根数、净盈亏、R、权益、收益率、来源），**点行展开**该笔开/平两条记录的**全部 24 个字段**（含手续费、可用资金、保证金、止损价、风险额、盈亏R、加仓、来源、说明等）；支持「展开全部 / 收起全部」；
   - 可切换「**全部字段明细表**」，24 列平铺；
   - **复制**：复制 CSV / 复制 TSV / 复制摘要（对齐文本表格，适合贴到笔记）；
   - **导出**：CSV（Excel 直接打开，带 BOM）/ TSV / JSON（含 meta + records + equity 曲线）/ JSONL，文件名形如 `复盘_RB0_day_20261005_124515.csv`，内容头部带元信息与统计（`# 合约=…`、`# 统计.胜率=…`）；
   - **结束复盘后记录、曲线、复制与导出依然可用**，不会因为会话关闭而丢失。
6. 右侧面板实时显示：当前 K 线、复盘持仓（方向/手数/均价/止损价/风险额/浮动盈亏）、资金（权益/收益率/回撤/手续费）、复盘统计（记录笔数/已平仓/胜率/盈亏比/累计R/净盈亏/平均持仓）。

复盘与回测共用同一套保证金 / 手续费 / 撮合与资金管理口径，所以练出来的手感可以直接迁移到策略参数上。

## 十、账户与银期转账

「账户 · 银期转账」页签管理**模拟账户**与**银期转账**：

- **多账户**：每个模拟账户有独立的 登录账号 / 登录密码 / 交易账户（资金账号，自动分配 `8` 开头 10 位）/ 资金密码（交易密码），并拥有**独立的持仓、委托、成交、资金与权益曲线**（状态文件互相隔离，切换登录即切换全部状态）；
- **新建账户**：点「创建并登录」立即生效；可同时绑定一张**首卡**（银行 / 卡号 12-19 位 / 银行交易密码 / 卡内余额），不绑卡也可以创建后再加卡；
- **登录 / 切换**：用登录账号 + 登录密码；删除账户需登录密码确认，**最后一个账户不可删除**，删除后其资金状态文件一并清除；
- **模拟银行卡**：可添加 / 解绑（解绑需银行交易密码；卡内余额随卡移出模拟系统，期货账户资金不受影响）；卡号列表中掩码显示；
- **银期转账**：
  - **转入**（卡 → 期货账户）：需**银行交易密码**，不超过卡内余额；
  - **转出**（期货账户 → 卡）：需**银行交易密码 + 资金密码**双重验证，且不超过**可用资金**（占用中的保证金须先平仓释放）；
  - 每笔转账在期货账户「资金流水」与银行卡「转账流水」双边留痕；
- **安全**：所有密码一律加盐 sha256 哈希保存在本机 `账户数据/users.json`，任何接口不回传明文；
- **默认账户** `sim001`：登录密码 / 资金密码 / 银行卡密码均为 `123456`（首次启动自动创建，带一张 100 万余额的工商银行卡）。

> 右上角的「资金注入 / 资金提取」是跳过银期环节的**快捷通道**（管理员口径，仅记流水）；要走真实业务流程请用本页的银期转账。

## 十一、交易设置（右上角「设置」）

| 设置项 | 默认 | 说明 |
|---|---|---|
| 保证金倍数 | 1.0× | 在东方财富公司保证金率基础上整体放大 |
| 手续费折扣 | 1.0× | 相对东方财富公司手续费标准；设 0.33 约等于交易所底线费率，设 0 为免手续费 |
| 市价单滑点 | 0 跳 | 1 跳 = 该合约最小变动价位，滑点始终对成交方不利 |
| 强平线 | 100% | 风险度达到该值触发自动强平 |
| 自动强平 | 开 | 关闭后只警示不强平 |
| 仅交易时段下单 | 关 | 默认关闭，便于非交易时段用最新快照价验证策略 |
| 涨跌停校验 | 开 | 拒绝超出当日涨跌停板的委托价，关闭后可任意挂价 |

## 十二、模拟盘口径（与真实交易的差异）

1. **保证金**按「最新价」实时盯市计算；真实交易所按「结算价」逐日盯市。
2. **浮动盈亏**在持仓期间累计展示，平仓时一次性转为已实现盈亏；真实账户每日结算时会划转。
3. **交易日**按本机自然日切换，「今仓」跨日后自动转为「昨仓」；真实市场的交易日从夜盘起算。
4. **成交**按最新价 / 委托价即时撮合，不模拟盘口排队与部分成交。
5. 不模拟**交割、期权、套保额度、持仓限额与梯度申报费**；**临近交割月的保证金上调**（官网「特殊合约参数调整」列，如 2610 合约 60%）按一般月份标准记录，未逐合约区分。
6. 交易时段判断未覆盖**法定节假日**调休。

## 十三、常见问题

**Q1：面板打不开 / 提示行情接口异常？**
行情接口连不上时会自动切换到离线快照，交易功能不受影响；点「刷新行情」可重试联网。本机代理软件可能导致误报，属正常现象。

**Q2：为什么有些合约显示「参数估算」？**
该品种不在 `品种参数.json` 中（理论上不会出现，已覆盖全部 87 个品种），会按默认 10 吨/手、10% 保证金估算，请以参数表为准。

**Q3：数据会不会上传？**
不会。行情由你的电脑直接请求东方财富公开接口；账户数据只写入本机 `账户数据/account.json`，没有任何中间服务器。

**Q4：想清空重练？**
右上角「设置」→「重置账户（保留资金）」清空持仓与记录但保留结存；「清空重置」则账户归零。也可以直接删除 `账户数据/account.json`。

**Q5：和「国内期货数据终端」什么关系？**
同一作者的配套项目。数据终端侧重**行情浏览与数据采集**（龙虎榜、加权合约、批量导出）；本面板侧重**模拟交易 + 策略**，自带行情看盘、技术指标、策略选股、自动交易、回测与复盘。两者共用 ECharts 依赖，离线快照直接取自数据终端的采集产出。

**Q6：K 线为什么走新浪而不是东方财富？**
东方财富的 K 线域名（`push2his.eastmoney.com`）在部分网络环境（含本机实测）会直接断连，而新浪财经期货接口稳定、历史更长（主力连续可回溯到 2009 年，4000+ 根日 K），所以 K 线/分时改用新浪，实时报价仍保留东方财富以复用涨跌停价。断网时自动回退本地 `行情缓存/`。

**Q7：策略怎么从「示例」改成自己的？**
策略库里对「穿越5日日K均线」点「复制」，改名后把参数里的 `周期` 改成你要的值（例如 10、20），或者换模板（双均线 / MACD / 布林带 / 唐奇安 / RSI / 自定义条件）。想先用历史数据验一遍，就去「策略回测」页跑同一套参数，看总收益与最大回撤是否可接受，再回策略库点「挂载」让它自动跑。

**Q8：挂载策略后为什么会自动成交？会动我的账户吗？**
会。挂载即代表授权后台按信号自动下单（默认「仅记录信号（不下单）」是勾上的，取消勾选才会真实下单）。所以建议：先不勾、观察几天信号质量 → 再去回测验证 → 最后才取消「仅记录信号」放它实盘跑。停用即停止。

## 十四、打包成 exe（双击即用）

项目根目录的 **期货模拟交易终端.exe** 是单文件绿色版（约 10 MB），双击即可运行：

- 自带 Python 运行时，目标电脑**无需安装 Python、无需联网装依赖**；
- 启动后自动打开浏览器进入面板；**关闭那个控制台窗口即停止服务**；
- 重复双击不会重复开服务（自动复用已运行的服务并直接开面板）；
- 功能与源码版完全一致，版本信息见 exe 属性。

**数据存哪里？** 全部在 exe 所在目录，关掉程序不会丢：

| 目录 | 内容 |
| --- | --- |
| `账户数据/` | 模拟账户、资金、持仓、成交、策略库（`acc_<uid>.json` 为各账户资金状态） |
| `行情缓存/` | K 线与行情缓存（断网时离线兜底） |

把 exe 单独拷到任意文件夹（U 盘、其它电脑）也一样用 —— 数据跟着 exe 走，等于绿色便携版。

**不重新打包就改配置？** 在 exe 旁边放一份同名文件即可覆盖内嵌资源：比如放自己的 `品种参数.json`（改保证金 / 手续费）、`vendor/quant-terminal.css`（改皮肤）。删除 exe 旁的同名文件即恢复内嵌版。

**杀毒软件提示？** PyInstaller 打包的程序偶尔被误报，添加信任即可；介意的话用源码方式运行（`启动模拟交易.bat`）。

**重新打包**：改完源码后运行 `python 打包成exe.py`（需本机装有 PyInstaller 与 Pillow，本机均已就绪），脚本会自动重画图标、生成版本信息与 spec 并构建到项目根目录，最后自动跑一次 `--help` 自检。构建期间请先关闭正在运行的旧 exe。
